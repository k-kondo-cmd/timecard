# 出退勤管理アプリ

QRコードを使った出退勤管理システムです。

## 機能

- QRコードをスマホで読み込むだけで出退勤を記録
- 出勤時間、退勤時間、勤務時間を自動記録
- 出退勤履歴の表示

## 使い方

### 1. QRコードの生成

`qr-generator.html`を開いて、従業員IDのQRコードを生成します。

### 2. 出退勤の記録

1. `index.html`をスマホのブラウザで開く
2. カメラへのアクセスを許可
3. QRコードをスマホで読み取る
4. 出勤または退勤が自動で記録されます

### 3. 履歴の確認

メイン画面で過去の出退勤履歴を確認できます。

## 技術スタック

- HTML5
- CSS3
- JavaScript (Vanilla)
- html5-qrcode (QRコード読み取り)
- qrcode.js (QRコード生成)

## データ保存

データはブラウザのLocalStorageに保存されます。
