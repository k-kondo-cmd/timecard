# 出退勤管理アプリ

QRコードを使った出退勤管理システムです。

## 特徴

- **単一のQRコード**で全従業員が利用可能
- 従業員ごとにQRコードを用意する必要なし
- QRコード読み取り後、従業員が自分のIDを入力・選択
- 出勤時間、退勤時間、勤務時間を自動記録
- 従業員ごとの出退勤履歴を管理

## 使い方

### 1. QRコードの生成と設置

1. `qr-generator.html`をブラウザで開く
2. 出退勤用QRコードが自動で生成されます
3. QRコードをダウンロード
4. 印刷して職場の入口など、従業員が読み取りやすい場所に掲示

**注意**: QRコードは1つだけで、全従業員が共通で使用します

### 2. 出退勤の記録

1. `index.html`をスマホのブラウザで開く
2. カメラへのアクセスを許可
3. 掲示されたQRコードをスマホで読み取る
4. 従業員選択画面が表示される
5. 自分の従業員IDを入力、または登録済みの場合はリストから選択
6. 確定ボタンを押すと出退勤が記録される

**出勤/退勤の判定**:
- 1回目の記録: 出勤
- 2回目の記録: 退勤（勤務時間が自動計算される）

### 3. 履歴の確認

メイン画面で全従業員の出退勤履歴を確認できます。
- 日付ごとにグループ化
- 従業員ごとの出勤時刻、退勤時刻、勤務時間を表示
- 本日の合計勤務時間を表示

## 技術スタック

- HTML5
- CSS3
- JavaScript (Vanilla)
- html5-qrcode (QRコード読み取り)
- qrcode.js (QRコード生成)

## データ保存

データはブラウザのLocalStorageに保存されます。
- 出退勤記録
- 従業員情報（IDと登録日時）

## 従業員管理

- 初回利用時に従業員IDを入力すると自動で登録
- 2回目以降は登録済みの従業員IDがリストに表示される
- 従業員IDで検索・絞り込みが可能
